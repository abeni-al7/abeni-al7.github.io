# abeni-al7.github.io

The personal portfolio site of Abenezer Alebachew Endalew, a single static page served with GitHub Pages.

Live site: https://abeni-al7.github.io

## Features

- Fixed navigation bar linking to the About, Projects and Contact sections
- Profile card with photo, title, social-media buttons and "Hire me" / "Collaborate" buttons
- Project tiles for TutorConnect (an Android app that connects tutors and students) and an AirBnB clone, each linking to its GitHub repo
- Contact section with links to GitHub, LinkedIn, X, Facebook, Instagram and email

## Built with

- HTML and CSS (`index.html`, `styles.css`), no build step
- Google Fonts (Roboto, Raleway)
- Boxicons and Ionicons, loaded from unpkg

## Run it

Open `index.html` in a browser. Any push to `master` is published by GitHub Pages.
